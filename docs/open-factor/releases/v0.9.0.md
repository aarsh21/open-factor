# Open Factor 0.9.0

A faster, calmer workout logger: a purpose-built keypad, a photo navigator, swipe to log or delete sets, notes that remember, exercise swaps, color palettes and motion throughout.

## Logging

- **Workout keypad** replaces the system keyboard for set values: digits, unit-aware −/+ steps that snap to the plate grid (hold to repeat), Next across fields and unfinished sets, and Log set, which moves straight to the next unfinished set without closing. Workout settings → Workout keypad restores the system keyboard.
- **Exercise navigator**: each exercise is its photo inside a progress ring (one segment per working set, warm-ups excluded), with superset grouping and a done badge. A **Next exercise** card appears when the current exercise is finished. Long names no longer truncate.
- **Swipe set rows**: swipe right to log (same validation, rest timer and keypad flow as the check button), swipe left to delete with Undo. TalkBack gets Log, Mark incomplete and Delete actions.
- **Rest controls** live in the fixed timer row, so completing a set never moves the sets under your thumb.
- **Effort (RIR)** is asked when you move to the next exercise, about the one you left, after rest and never while you are typing. Workout settings can restore "Right after the last set".
- **Notes at three levels**: pinned (every time), template (only in workouts started from that template) and a muted, dated "Last time" placeholder that is never copied and can be dismissed.
- **Swap exercise** suggests up to eight same-muscle alternatives available at the workout's gym, with Search all. Completed sets stay with the original; template workouts ask "Just today" or "Also update template"; Undo restores everything until you make another edit.

## Look and motion

- **Color palettes**: Charcoal (default, unchanged), Midnight, Ember, Moss and Mono, each with dark and light variants that meet WCAG AA text contrast. Settings → Appearance shows live swatches and cross-fades the app.
- **Navigation motion**: deeper screens push in, back reveals, tabs fade through; the floating navigation rides the same transition. Android 14+ predictive back scrubs the transition with your finger. Everything respects Android's Remove animations.

## Performance

- Typed set values are saved off the main thread and coalesced (50 rapid edits → 1 write) and flushed whenever the app pauses; completions and every other change still save before they show.
- The workout clock no longer recomposes set rows every second, typing recomposes only the edited row, scrolling no longer recomposes the app shell, and fonts are parsed once per process.

## Removed

- **Import Fitbod CSV** is removed. Workouts and custom exercises it imported stay in History. Spreadsheet (XLSX) program import, backups and exports are unchanged.
