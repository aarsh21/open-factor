# Open Factor 0.8.0

Exercise previews without letterbox gutters, plus reviewed Fitbod strength-history imports.

## Changes

- Compact exercise photos now fill their rounded preview frames instead of fitting a narrow portrait inside a wider slot. The shared component covers the exercise library, logger, workout/template composers, program editor, saved template lists and history summaries.
- Loading photos use the theme's raised neutral surface. Missing or failed images show an accessible exercise icon instead of an empty tile. Transparent licensed illustrations keep a white canvas for contrast.
- Full demonstration photos and videos retain their natural-aspect presentation. This change does not crop the instructional guide, alter original media bytes, or change anatomy and personal-photo framing.
- Settings → **Import Fitbod CSV** previews the supported 18-column strength-sets export and appends completed history after exercise matching, skip review and explicit acknowledgement. Existing history, active workouts, programs, templates and drafts are not replaced.
- Reimporting skips existing Fitbod workout IDs and preserves local edits. The importer rejects malformed, duplicate or conflicting records rather than silently dropping sets.

## Fitbod import scope

Recorded kilograms, repetitions, warm-ups and timestamps become completed actual sets. AMRAP flags and varying rest values are preserved in exercise notes; they are not converted into guessed RIR, failure, duration or special set kinds. Workouts have one source timestamp, so missing duration is represented as **zero minutes** with a persistent explanatory note, not an estimate.

Only unique normalized catalog names/aliases match automatically. Other names require an explicit movement/equipment choice or skip. Per-side values are never doubled or divided. Skipping all exercises in a workout omits that workout; reimporting does not fill previously skipped exercises into an existing workout ID. Duration/distance sets and other CSV schemas are rejected.

See the [exact format, privacy and resource boundaries](../FITBOD-IMPORT.md). The existing [XLSX program-target importer](../SPREADSHEET-IMPORT.md) remains a separate entry point.

## Update safety

The package and signing certificate are unchanged. Android accepted an in-place signed update from the 0.7.0 baseline on the disposable API26 emulator. This release adds no data-schema migration and retains existing backup/restore support. **Export and retain a complete backup before updating or importing history.** Older testing alphas can use another signing key; see [migration guidance](v0.2.0.md).

The native import tests verify that an active workout and non-history data remain unchanged after a confirmed append, that the store reloads the result, and that repeating the import creates no duplicate. A full semantic pre/post-upgrade personal-backup comparison is not claimed for this release.
