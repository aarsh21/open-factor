# Open Factor 0.5.2

All exercise targets are visible together, past workouts can be corrected, and logging finishes with one optional effort rating.

## Changes

- Muscles shows every primary and secondary target together on the original front/back figures. Male/Female remains available; individual muscle tabs are removed.
- Exercise history fills the content width and shares the aligned recorded-set table with workout summaries. Dates and workout names lead each visit; opening its header leads to the saved workout.
- Edit workout corrects name, date, notes, actual metric values, completion and recorded effort. Add/remove sets or exercises before Save. A separate durable draft preserves history and active sessions until saving; invalid values and stale-record conflicts block Save. Back offers discard confirmation.
- Log all sets validates every unfinished log before completing any of them. Once all exercise logs are complete, one optional sheet asks how many reps remained on the last working log. It records RIR, as shown in the supplied example, rather than treating those choices as a 1–10 RPE score. Earlier set ratings stay unchanged. Skip/rating survives recreation; Rate last set allows correction.
- Dashboard has calendar Week/Month totals and matching muscle workload, with bounded previous/next navigation. The repeated daily training bar chart is removed; steps charts remain available.
- The shared image loader now initializes through the application factory, including when imagery is requested before MainActivity.

## Review

| Before | After | Why |
| --- | --- | --- |
| One target muscle visible per selection | All targets with front/back highlights | Read the complete exercise at a glance |
| Narrow history card and stacked values | Full-width dated set table | Compare actual recorded values |
| Repeated dashboard counts and bars | Week/Month counters and matching workload | One clear period summary |
| Inline effort on every set | Validated bulk logging and one final optional rating | Keep repeated logging fast |
| Saved mistakes required deletion | Isolated editable draft with Save/discard | Correct history safely |
