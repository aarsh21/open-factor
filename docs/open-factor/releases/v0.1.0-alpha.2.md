# Open Factor 0.1.0-alpha.2

Onboarding and floating-navigation testing checkpoint. Open Factor remains an incomplete reconstruction of MacroFactor Workouts.

## Install and test

Download **open-factor-0.1.0-alpha.2.apk** and open it on Android 8.0 or newer. Package `org.openfactor.app`, version code `3`; debug-signed with the same testing key as alpha.1. Back up existing Open Factor data in Settings before updating. No account is required.

- New installs enter setup. Existing installs keep their dashboard; open **Settings → Set up Open Factor** to try it.
- Setup follows the observed **Basics → Gym & Equipment → Program** sequence. Enter a local profile, choose equipment, then create a manual program or defer it.
- Partial setup survives restart and can be deferred/resumed without replacing workout history or saved programs.
- The Nuvio-style navigation capsule overlays content with subtle scroll/depth and tab-selection animation, while its touch targets stay anchored. Root page content extends behind and around the capsule to the bottom edge, without a full-width backing strip. Exercise search floats above it, and trailing scroll space keeps final controls reachable.
- System animation controls are respected.

Independent review still requires rebuilding the welcome composition, restoring overview type/rail rhythm and expanding gym selection targets. The source welcome artwork/account flow and unrecorded intermediate forms are not fully reproduced. Health Connect, smart programming and XLSX are explicitly unavailable. Height/bodyweight setup values are local profile data and do not drive smart programming.

## Existing features and limits

Includes the alpha.1 offline catalog, exercise search/favorites, gym profiles, workout logger/history/templates, manual seven-cycle programs, units and JSON backups. All 1,345 descriptive exercise records are present. Private source photos, instructions, fonts, anatomy/equipment artwork and original exercise videos are excluded from this public APK. Original video acquisition remains a deferred future task.

Full source parity, smart generation/progression/deload, body metrics/analytics, advanced sets/supersets, calendar placement, sync/integrations, exact program controls and authenticated catalog-count discrepancies remain open. Actual TalkBack speech, all large-font/keyboard paths and physical-device performance are unverified.

## Validation

Build, lint and 26 unit tests pass. Emulator checks cover setup persistence/defer/recovery and preservation of training data on Android 8/API 26 and Android 15/API 35. Corrected-build native checks cover fixed tab bounds, Settings footer clearance, exercise search above the pill, tab navigation with animations disabled and recorded motion. Setup capture states were separately seeded after the foreground correction and restored afterward; combined test evidence is not represented as one uninterrupted run. The independent navigation-content review is **ship at that scope only**; onboarding retains a scoped **rebuild** verdict. No new connected instrumentation run or full-clone acceptance is claimed.
