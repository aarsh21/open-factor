# Open Factor 0.2.0

Open Factor now opens on a simple workout screen. Choose kilograms or pounds, start a workout, select an exercise, and log your sets. This release prioritizes straightforward logging over reproducing another application's interface.

## Install

Android 8.0 or newer. Download `open-factor-0.2.0.apk` from the [GitHub release](https://github.com/aarsh21/open-factor/releases/tag/v0.2.0) and verify it against `SHA256SUMS`.

**Testing-alpha migration:** this release uses a dedicated, persistent release signing key. Its certificate differs from the earlier debug-signed alphas. Before uninstalling an alpha, use Settings → Export Backup and keep the complete backup outside the app. Install 0.2.0, then use Settings → Restore Backup. Uninstalling without a backup deletes local workouts and photos. Android does not permit an in-place update signed by a different key.

## Changes

- One-screen setup and a direct Start workout action.
- Search at the top of exercise selection, optional filters, and uncluttered exercise rows.
- Compact exercise switching, visible Finish, and one-tap Warmup and Add set.
- New working sets reuse the preceding load and reps while resetting completion and effort. Split sides retain independent values.
- Keyboard-aware layouts, labeled set fields, validation, and confirmation before removing logged sets.
- Automatic restoration of the active workout when reopening the app.
- Optional ongoing-workout and background rest notifications, including direct resume, stale-timer cancellation and reboot restoration.
- Recovery of an earlier valid saved snapshot when possible, with unreadable originals preserved for export rather than silently discarded.
- Bundled DM Sans and 44 licensed Everkinetic illustrations for 21 reviewed exercise variants, with offline attribution and legal text.
- A small optimized release, explicit private-asset exclusion, signing verification and SHA-256 receipts.

Templates, programs, history, exercise customization, gym profiles, body data and complete local backups remain available. Training does not require an account or a network connection.

## Verification

The release evidence archive contains the exact signed-artifact receipt, certificate report, unit and Android instrumentation results, and native screenshots/recordings. The repository's `QuickWorkoutJourneyTest` exercises initial setup, selection, actual weight/reps, a completed set, warmup insertion, activity recreation, completion and history. Storage tests cover workout data, preferences, gyms, original progress photos, complete backups and corrupt-data recovery. Licensed-media tests decode and hash-check all 44 shipped images.

Local validation covers Android 8/API 26 and Android 15/API 35 emulators. Release-signed installation, process recovery, notification behavior and the visible workout journey are checked separately from debug instrumentation. The public-APK verifier checks the exact asset allowlist, all preview hashes, unique catalog IDs, ZIP integrity and the size limit. CI repeats build/lint/unit checks and the API 26/35 device matrix.

The final local runs passed 114 unit tests in each build variant and 17 instrumented tests on each Android version. [GitHub CI passed all three jobs](https://github.com/aarsh21/open-factor/actions/runs/40776857929). The [artifact receipt](v0.2.0-validation.json) pins the exact APK and signing-certificate hashes. The independent review scored both reported consistency fixes resolved; that verdict covers those fixes, not universal defect freedom. The release evidence also includes a real Gboard input check at font scale 1.3 and a background rest alert opening the active workout.

## Scope and limits

- Public illustration coverage is 21 of 1,345 catalog exercises. Other exercises use an icon; the public release contains no demonstration videos or recovered proprietary assets. [Full media attribution and coverage](../LICENSED-MEDIA.md).
- Android notification permission is optional. Precise background timing requires special access available through Rest timer → Precise timer alerts. Android may delay approximate reminders; force-stop suppresses alarms until reopening. Device power restrictions and notification settings can also affect delivery.
- Accounts, cloud synchronization and Dokploy/Hono/RustFS video hosting are not included. All training data stays on the device; keep exported backups.
- Emulator results establish the tested flows. Physical-device performance, OEM battery restrictions, actual TalkBack speech and broad tablet behavior have not been certified by these runs.
