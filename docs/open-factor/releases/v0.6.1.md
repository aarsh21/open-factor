# Open Factor 0.6.1

Choose a split, make it yours, then train. This release fixes the Health Connect return during setup and adds editable starter templates.

## Changes

- Connecting Health Connect from onboarding returns to the baseline step automatically after provider readings are saved. Denial, missing permissions and failed imports keep the connection screen available. Manual sync from Settings stays on Health Connect.
- Four starter splits include seven explicit workout/rest days: Upper/Lower/Push/Pull/Legs, Upper/Lower twice weekly, Bro split and Full body. Preview each day's muscles, exercises and prescriptions before copying it into your templates.
- Each copied workout is independently editable. Rename it, reorder or replace exercises, and set working-set counts, rep targets and rest times. Your existing templates remain available.
- Template composition now uses the shared exercise picker: ranked search, muscle shortcuts, equipment/resistance/type/laterality filters, favorites, multi-selection and original exercise guides. The editor shows the selected target muscles together.
- Starting a template creates the prescribed sets with empty actual weight and reps. Targets are displayed separately. An active workout cannot be overwritten; raw editor inputs survive recreation and unsaved changes have an explicit discard action.
- Backups and workout exports retain template prescriptions and split layouts, while older templates remain compatible.

## Review

| Before | After | Why |
| --- | --- | --- |
| Successful setup import stopped on Connected | Saved import returns directly to onboarding | Continue setup without an extra Back tap |
| Build every template from scratch | Four editable starter splits | Provide a useful starting point without a program wizard |
| Template selection lacked the full filters | Shared search, filters and multi-selection | Find the same exercises consistently throughout the app |
| A long split preview repeated all workouts | Seven selectable days with a pinned day action | Inspect one day clearly while keeping rest days visible |
| Templates stored exercise identities only | Editable set, rep and rest targets | Prepare the session without inventing logged performance |
