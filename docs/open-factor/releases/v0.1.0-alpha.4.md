# Open Factor 0.1.0-alpha.4

Media-enabled Android testing prerelease with live training-value corrections. This remains an incomplete reconstruction of MacroFactor Workouts.

## Install

Download **open-factor-0.1.0-alpha.4.apk** and install over your existing Open Factor build. Android 8.0 or newer is required. Package `org.openfactor.app`, version code `5`; debug-signed with the same testing key as earlier alphas. Back up your data in Settings before updating. No account is required.

## Changes

- Includes the recovered reference-media pack: photographs for **619 of 1,345 exercises**, 1,831 mapped images, anatomy and equipment graphics, plus available reference instructions/fonts. Every mapped image path exists in this APK.
- Weekly Dashboard working-set, exercise, muscle and volume values derive from saved workouts plus the current session. Completion, undo, restart and finish retain their expected totals without double-counting a workout.
- No active program falls back to All Workouts. Program comparisons use actual stored cycle sets/skips rather than unrelated workout-template lengths or a fabricated muscle target.
- Levels includes completed working sets from the current workout. List and contribution dialog consistently show weekly averages for seven-, 30- and 90-day periods.
- Retains the fixed-anchor Nuvio capsule, subtle motion and page content continuing behind it, plus resumable local setup.

Working analytics exclude warm-ups; session/history completed-set counts include them. Program comparisons are explicitly labeled cycle plans and are local reporting policy, not a recovered calendar schedule or source analytics algorithm.

## Media provenance and limits

Unlike the source-only alpha.2 APK, this explicitly requested release includes the existing pack extracted from the user-supplied reference APK. Application code is GPLv3; included reference media retains its original ownership and is not relicensed by Open Factor. The reference directory remains excluded from Git and automatic source-only CI builds.

**726 exercises still have no recovered photo mapping. No original exercise demonstration videos are bundled.** Future server-side video acquisition remains deferred. A later source-only APK without this pack will use media fallbacks again.

## Known unfinished work

Full source parity, welcome composition and overview hierarchy, gym selection target sizing, source account/Health Connect/sync, smart programming/progression/deload, body metrics/complete analytics, advanced sets/supersets, calendar placement, XLSX and exact program/logger controls remain open. Authenticated catalog counts still differ from static recovery. Actual TalkBack speech and complete enlarged-font/keyboard/hardware verification remain unverified.

## Validation

Build, lint and **31 unit tests** pass for reference and clean source-only builds. The main synthetic own-app logger/metric/media checks on API26/API35 combine UI-driven prefixes and separately resumed tails after test-helper corrections; they are not uninterrupted full-run passes. Representative photos/anatomy render in both emulator capture sets. Focused corrected-build period checks passed independently on both emulators: three working sets display 0.7 sets/week over 30 days and 0.2 over 90 days in both list and dialog, with original app data restored.

Independent review approved the single Levels reporting correction and retains the bounded Dashboard/private-photo acceptance; full clone acceptance is not granted. No new connected instrumentation run or source-video playback is claimed.
