## Changes

- One Health Connect Connect/Sync action requests read access and continues from Android consent into real weight, body-fat and daily step reads. Partial grants work independently. Imported readings and sync state persist; stale connected data refreshes while foregrounded. The production app requests no provider write permissions.
- Search all 1,345 exercises with ranked names, aliases, common abbreviations, reordered/combined terms and bounded typo matching. All equipment is the default; the full result list remains available. Original videos cover 619 exercises, not every catalog record.
- Plus opens shortcuts again. Log Weight uses a bottom sheet that preserves the current destination and active workout. A compact exercise selector replaces oversized horizontal logger tabs and retains entered set values when switching exercises.
- Full-width weight readings and chart show recorded daily weight plus a labeled trailing seven-calendar-day mean. Manual readings win on a shared date; missing days are omitted, never zero-filled. Help is optional.
- Dashboard and Workout show recorded training counts and weekly working-set bars. Original front/back anatomy, direct/indirect set counts and exercise drilldowns use direct + 0.5 × indirect weighted totals. Week/30-day/90-day views show actual totals, without fabricated strength or recovery scores. Programs remain accessible.
- Frameless portrait video and thumbnails preserve the full movement frame. Explicit Play starts one repeating playlist through all available camera angles; direct camera selection and existing speeds remain available. Opening guidance still performs no video download.
- Date-dependent views refresh on foreground resume and local-day changes. Rest has one visible countdown while its banner is active. Drilldown and unsupported-export labels describe the actual action.

## Scope

Version is `0.4.0` / code `8`, package `org.openfactor.app`, minimum Android 8/API 26. Health Connect requires Android 9+ and an available provider; Android 14+ includes it. Original videos require a compatible HEVC decoder and bundled, streamed or retained cached bytes. The 128 MiB LRU cache can evict clips. No account is required.

The media inventory and original identities are unchanged. The [0.3.0 record](v0.3.0.md) contains the prior full-upload/readback evidence for all 1,831 objects; the current changes do not constitute a new full-service audit. Media ownership remains separate from the GPL code. See [packaging](../MEDIA-PACKAGING.md), [asset provenance](../ASSETS.md), [training counts](../LIVE_DATA.md) and [body charts](../BODY-CHARTS.md).

Checks cover their named emulator configurations and exercised journeys. They do not establish universal device compatibility, personal-provider coverage or a guarantee that every interaction is flawless.
