# Open Factor 0.1.0-alpha.1

First Open Factor Android testing prerelease. This is a development checkpoint, not a complete replacement for MacroFactor Workouts.

## Install

Download **open-factor-0.1.0-alpha.1.apk** from this release and open it on Android 8.0 or newer. Allow installation from your browser or file manager when Android requests it. Package: `org.openfactor.app`; version code: `2`. This is a debug-signed testing APK and can coexist with Nuvio and MacroFactor Workouts. Back up existing Open Factor data in Settings before updating.

The attached SHA256SUMS file can be used to verify the download. No account or source-app sign-in is required.

## Ready to test

- Search and filter 1,345 exercise records; favorites and custom exercises.
- Gym profiles, equipment lists and local muscle set levels.
- Workout logging with reps, weight, RIR, warm-ups and notes; pause/resume, automatic rest and exercise auto-next.
- Persistent sessions, completion summaries, history and reusable workout templates.
- Manual programs with rest/workout days, seven-cycle rep/RIR targets, skip/rest overrides, library activation and selected-cycle workout launch.
- Preservation of differentiated cycle targets through reopening, scope navigation and unchanged Save.
- Kilograms/pounds, JSON backups, Nuvio-style floating navigation and grouped Settings.

## Known limits

The public APK contains factual catalog metadata and Material icons. Privately extracted exercise photos, original instructions, fonts, anatomy/equipment artwork and videos are **not bundled**. Media-dependent surfaces use their available fallbacks. No original exercise-demo files have been recovered; future phone-assisted acquisition is deferred.

Smart program generation, automatic progression/deload, body metrics, complete analytics, advanced sets/supersets, XLSX, calendar placement, integrations/sync and complete source UI parity remain unfinished. Exact target controls, the icon selector and saving-scope sheets remain open. Static browse memberships still differ from authenticated reference counts. Actual TalkBack speech and complete input recovery remain unverified.

Build, lint and 23 unit tests pass at this checkpoint. Native program/session flows and differentiated-target preservation were checked on Android 8/API 26 and Android 15/API 35; the API 26 correction check resumed from its saved synthetic plan after a test scrolling fix. The independent manual-program review remains **fix**, with no full clone acceptance.

## Useful test paths

1. Start a workout, add an exercise, complete a set, restart the app and resume it; finish and inspect history.
2. Create a manual program, set different Cycle 1 and Cycle 2 targets, save/reopen it and verify they remain distinct.
3. Activate the plan and start the selected day/cycle. Check planned versus actual RIR and its rest override.
4. Export a JSON backup and check your gym, program and history data.

Report the steps, expected result, actual result and Android version with any issue. Avoid attaching private backup or account data publicly.
