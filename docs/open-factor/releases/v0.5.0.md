## Changes

- Workout exercises use horizontal tabs again. Switching is one tap; the selected tab stays visible and the set fields retain their values. The current exercise has its photo, name and Guide action.
- Every exercise picker uses the shared ranked search, including Create template and dashboard customization. Reordered queries such as `bench press incline`, aliases, equipment/muscle combinations and bounded typos work across these surfaces. Rapid Add taps cannot submit twice from a departed picker.
- Plus offers Create template for reusable workouts. New Program is removed from shortcuts and their configuration; existing program data and the separate Programs destination remain available. Legacy shortcut IDs still decode from backups.
- The dashboard restores three Muscles / Sets / Exercises circles using actual completed training. Empty sections and the duplicate blank Start workout block are removed. The navigation pill has a neutral charcoal rim.
- History uses a week calendar and dated timeline with original muscle maps, real duration, exercise/working-set counts and volume, exercise summaries and Open/Repeat actions. No calorie estimate is invented.
- Steps has interactive 7/30-day charts, day selection, observed-day total/average/best values and a sync timestamp. Missing aggregates remain unknown; a real zero remains measured. After initial consent, Health Connect refreshes once on every app foreground visit, even seconds after the previous sync.
- The video fills the available width at its natural portrait aspect and restores side-mounted angle previews. No added black side margins and no movement cropping. Short viewports scroll the full frame; playback controls and Retry stay above the picture. The ordered camera playlist still repeats after explicit Play.
- Log Photos opens the native camera directly. Full-resolution images are stored privately, with date, pose and notes. Temporary camera output survives interrupted import for replay after recreation and is removed after delivery or cancellation. All-hidden photo poses skip automatic capture.

## Scope

Package `org.openfactor.app`, version `0.5.0` / code `9`, minimum Android 8/API26. Health Connect needs Android 9+ and an available provider. Search covers 1,345 catalog exercises; original videos cover 619 of them, with 1,831 exact video objects. Static guidance is bundled; video uses the existing HTTPS service and bounded 128MiB cache. This release changes no media objects; prior full-library upload/readback evidence remains in [0.3.0](v0.3.0.md).

Native checks cover their named emulator configurations and exercised journeys. They do not establish universal hardware compatibility. Provider-fixture evidence uses explicit synthetic TEST records in the real Android provider, not personal history or an app-local mock.
