# Manual program direction contract

Mode: Operate. Platform: Android. Artifact: `openfactor/app/`.

## THESIS

Reproduce the captured manual program workflow: name/color, an initial Rest day, ordered day tabs, exercise selection and editable seven-cycle set targets. Smart generation remains a distinct unresolved algorithm.

## OWN-WORLD

Preserve the inherited charcoal, white actions, DM Sans and geometric heading rules in DESIGN.md. Program colors identify user-selected plans. Primary navigation and Settings retain the user's Nuvio exceptions.

## STORY

Create a manual program, turn a rest day into a workout by adding exercises, configure targets, save or activate it, and start a day without losing an ongoing session. Drafts and programs persist locally and through backup.

## FIRST VIEWPORT

Show Create Program, ordered day tabs and Add Day. Below, show day actions and Rest Day explanation or exercises with seven-cycle targets. Save to Library and Activate Program anchor the bottom; editing must remain usable above the keyboard.

Native Compose, source-video chapter Program Manual and source-scratch captures as reference. Seven cycles and a single Standard Set are observed defaults. Local save/activation/start semantics are reconstructed and require independent verification; source drafts were not saved. No claim of complete program, superset, Myo/Failure, XLSX, generation or progression parity.
